First release of the Rust version (replaces the Python prototype).

- Effects static, wave, breathe, neon, off; brightness 0-9, speed 0-4, wave direction, seven colour slots, cycle.
- Reports exactly as G-aim Control Center 1.1.5 sends them, tested on the pad (Windows).
- Command line `kmp6_rgbtool` and GUI `kmp6_rgbtool_gui`, English and German.
- The GUI draws the pad (edge and logo zone) and animates it at the speeds measured on the real pad; two columns in
  wide windows.
- The button on the pad changes the effect without telling the PC: "Pressed the button on the pad" in the GUI (or
  `kmp6_rgbtool next`) takes the same step, so window and pad agree again.
- The last setting is stored by the tool (the pad cannot be read back); `off`/`on` for shutdown and startup.
- Windows: `install_shutdown.ps1` switches the LEDs off at shutdown (optionally on again at logon with `-LogonOn`).
  Linux: udev rule and systemd unit in the package.

Linux has not been tried with the pad yet.
