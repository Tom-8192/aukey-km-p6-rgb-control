The tool starts without colour cycling now.

- Without a stored setting the pad shows slot 1 (static red) instead of G-aim's "cycle through all seven colours";
  the GUI checkbox "All seven colours in turn" starts unticked, and `kmp6_rgbtool reset` / the GUI button
  "Factory setting" send static red. Settings you already stored stay as they are.
- The GUI was tested on Linux on the pad (Bazzite, Wayland), also while OpenRGB with the
  [OpenRGB KM-P6 plugin](https://github.com/Tom-8192/OpenRGB-KMP6-Plugin) was running.

Not tried on Linux yet: the systemd unit `kmp6-off.service`.
