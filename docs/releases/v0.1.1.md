Linux works with the pad now.

- The lighting interface of the pad has no endpoint, so Linux creates no `/dev/hidraw*` for it and 0.1.0 reported
  "mouse pad not found". The tool now sends the reports as control transfers through usbfs
  (`/dev/bus/usb/BBB/DDD`, no libusb needed); a hidraw node is still used if a kernel creates one.
- The udev rule `70-kmp6-rgbtool.rules` now also grants access to the USB device. Install it again (see README), or
  rely on OpenRGB's udev rule, which already covers the pad.
- Interface 2 is claimed only while a setting is sent, so the tool runs alongside the new
  [OpenRGB KM-P6 plugin](https://github.com/Tom-8192/OpenRGB-KMP6-Plugin) (shared lock).

Tested on Bazzite (kernel 7.2) on the pad: command line (`info`, `set`), parallel commands. The GUI and the systemd
unit were not tried on Linux yet.
